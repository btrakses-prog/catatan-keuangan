# Kas WiFi Sederhana

Versi ini memiliki:
- Dashboard responsive laptop/smartphone
- Input transaksi: tanggal, uang masuk/keluar, nominal, keterangan
- Ralat/edit transaksi
- Hapus transaksi
- Filter tanggal
- Print dan PDF
- Pengaturan jenis pembagian persentase yang dapat DITAMBAH, DIUBAH, atau DIHAPUS
- Total persentase ditampilkan di pengaturan

Instalasi:
1. Import database.sql ke MySQL/phpMyAdmin.
2. Atur DB di config.php.
3. Jalankan `composer install` untuk PDF.
4. Login admin / admin123.
